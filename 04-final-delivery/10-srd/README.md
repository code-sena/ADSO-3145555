## Descripción del proyecto

SRD es una plataforma para la gestión digital de las Juntas de Acción Comunal (JAC). Su propósito es organizar en un mismo sistema la administración de información y procesos que tradicionalmente se manejan mediante registros y documentos dispersos.

El sistema está diseñado con arquitectura de microservicios y enfoque multi-tenant para separar la información de cada junta. Integra funciones de autenticación y gestión de roles, registros, archivos, configuración, calendario, notificaciones, tesorería, inventario, chat y auditoría.

**Tecnologías principales:** PHP, Laravel, React, TypeScript, React Native, Expo, Electron, MySQL, Docker Compose, Nginx y Reverb.

**Aplicaciones:** web, móvil y escritorio para Windows.

**Enlace del sistema:** [SRD — Acceso web](https://srv2093837.hstgr.cloud/login).
