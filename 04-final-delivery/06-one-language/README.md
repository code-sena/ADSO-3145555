## Summary / Resumen

- **Problem it solves / Problema que resuelve:** Facilita la comunicación básica mediante reconocimiento de un vocabulario acotado de LSC y presentación de resultados como texto y, opcionalmente, voz. No sustituye intérpretes ni traduce conversación continua.
- **Target users / Usuarios:** Personas sordas o con hipoacusia, personas oyentes, familias y equipos de apoyo; validar el público institucional definido.
- **Main features / Funciones principales:** Registro e inicio de sesión; reconocimiento de señas aisladas en tiempo real; resultado en texto/voz; guardado y consulta del historial; ajustes de accesibilidad y permisos.
- **Technology stack / Tecnologías:** Web React 19/Vite; móvil React Native/Expo; backend Java 17/Spring Boot; IA Python/FastAPI, MediaPipe y TensorFlow/Keras; PostgreSQL 15 y Liquibase; Docker y Nginx.
- **Production URL / URL en producción:** https://onelanguage.tech (web); https://ai.onelanguage.tech/health (salud del servicio IA).
- **Demo credentials / Credenciales de prueba:** No incluidas en este repositorio; solicitar al equipo una cuenta temporal. Nunca publicar contraseñas reales.
