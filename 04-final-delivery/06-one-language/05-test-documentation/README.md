## Format / Formato

- English file names use no spaces or accents. / Los nombres en ingles no llevan espacios ni tildes.
- Files over 50 MB go to Drive and are listed in the project README. / Los archivos de mas de 50 MB van a Drive y se relacionan en el README del proyecto.
- Do not add passwords, tokens, keys or real user data. / No incluya contrasenas, tokens, llaves ni datos reales de usuarios.
