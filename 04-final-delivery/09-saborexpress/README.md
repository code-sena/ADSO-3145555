## Summary / Resumen

- **Problem it solves / Problema que resuelve:** Centraliza la operación de restaurantes: sedes, mesas, pedidos, cocina, caja, pagos y domicilios.
- **Target users / Usuarios:** gerente, administrador, mesero, cajero, cocina, repartidor y cliente.
- **Main features / Funciones principales:** gestión de sedes, catálogo, mesas, pedidos, cocina, caja, pagos Wompi, facturación, entregas, notificaciones y control por roles y sede.
- **Technology stack / Tecnologías:** API ASP.NET Core 8, Entity Framework Core y PostgreSQL; web Next.js y TypeScript; móvil React Native/Expo; comunicación en tiempo real con SignalR; despliegues declarados en Render y Vercel.
- **Production URLs / URLs en producción:** [web](https://sabor-express-web.vercel.app) · [API](https://saborexpressback.onrender.com). La disponibilidad y el inicio de sesión deben verificarse sobre el commit/tag evaluado.
- **Demo credentials / Credenciales de prueba:** se entregan por canal privado; no se publican contraseñas reales en este repositorio.
