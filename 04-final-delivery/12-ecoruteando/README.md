## Summary / Resumen

- **Problem it solves / Problema que resuelve:** Congestión vehicular urbana en ciudades intermedias (Neiva), falta de visibilidad del impacto ambiental individual en los desplazamientos diarios, ausencia de herramientas que incentiven la movilidad activa/peatonal y carencia de un canal ciudadano colaborativo para reportar obstáculos viales en tiempo real.
- **Target users / Usuarios:** Ciudadanos, peatones, ciclistas, conductores urbanos, administradores municipales y entidades ambientales interesadas en monitoreo de movilidad ecológica y auditoría de emisiones bajo lineamientos ISO 14001 / ISO 14064.
- **Main features / Funciones principales:** Cálculo de rutas multimodales (conducción vs. caminata) con estimación matemática en tiempo real de emisiones de CO₂ y calorías quemadas; ruteo asistido por voz y telemetría GPS con persistencia offline de coordenadas; módulo comunitario para reporte georreferenciado de obstáculos en vía con evidencia fotográfica y votación comunitaria; catálogo de puntos de interés (POIs) eco-turísticos; gestión de rutas favoritas; exportación formal de historiales en PDF y CSV para auditoría; y control de acceso robusto RBAC con autenticación de dos factores (2FA TOTP).
- **Technology stack / Tecnologías:** Backend ASP.NET Core 8 Web API (Clean Architecture, Monolito Modular, CQRS con MediatR, FluentValidation), Base de Datos PostgreSQL 16 con extensión espacial PostGIS 3.5 y migraciones Liquibase, Frontend Web React 18 + Vite + Tailwind CSS, App Móvil React Native + Expo SDK 52 / 57, y despliegue en la nube mediante Render y EAS Build.
- **Production URL / URL en producción:** Frontend Web: `https://ecoruteando.onrender.com` / Backend API: `https://ecoruteandobackend.onrender.com`
- **Demo credentials / Credenciales de prueba:** Usuario estándar: `demo.usuario@ecoruteando.com` / Administrador demo: `admin.demo@ecoruteando.com` (solicitar credenciales activas sin contraseñas públicas en repositorio)
