# ADR-004: Estrategia de versionamiento con Git

## Contexto
Se requiere organizar el desarrollo.

## Problema
No existe flujo de trabajo definido.

## Decisión
Se manejara una estrategia para manejar el versionamiento la cuales seran los ambientes
- main
- qa
- develop

## Justificación técnica
Permite separar desarrollo, pruebas y producción.

## Consecuencias
+ Orden en el desarrollo
+ Mejor control de cambios
- Requiere disciplina del equipo
