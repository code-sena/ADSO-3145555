# ADR-002: Implementación de roles y permisos

## Contexto
El sistema requiere control de acceso.

## Problema
No existe diferenciación clara de permisos.

## Decisión
Se implementará RBAC (Role-Based Access Control).

## Justificación técnica
Facilita escalabilidad y mantenimiento de permisos.

## Consecuencias
+ Mayor seguridad
+ Mejor trazabilidad
- Mayor complejidad en consultas
